# HIDDEN DEPENDENCIES & BREAKING RISKS

1. **Supabase Row Level Security (RLS) & Unique Constraints:** 
   - The migration schema contains `CREATE UNIQUE INDEX unique_personal_renewal ON public.temp_leads_basics USING btree (phone, policy_type, renewal_date)`. If `policy_type` changes to an array or JSONB array, this constraint will completely fail.
2. **Reporting Aggregations:**
   - `get_report_summary` RPC explicitly filters using `policy_flow` and `insurence_category` strings. Changing these to arrays requires rewriting the PostgreSQL RPC to use `?|` or `@>` JSONB array operators.
3. **Email Templates:**
   - `email_templates` table maps strictly to singular `insurance_category` and `policy_type`. Sending an intake form for a "Home + Auto" lead will fail unless the system knows which specific template ID to fetch.
4. **Update Stage Validations:**
   - The pipeline engine (`UpdateStageModal.tsx`) dictates required documents based on a singular policy type. Supporting multiple policies implies a union of `mandatory_fields`, which exponentially complicates UI validation.

---

# RECOMMENDED IMPLEMENTATION ORDER

**Phase 1: Database & Types (Foundation)**
1. Write a Supabase migration to alter `policy_type` to `policy_types` (JSONB Array `['auto', 'home']`).
2. Remove the `unique_personal_renewal` constraint and rewrite it to handle array containment.
3. Update `lib/supabaseServer.ts` and `types/supabase.ts` (if present) to reflect the JSONB array.

**Phase 2: API & Logic (Backend)**
4. Update `/api/update-stage/route.ts` to handle arrays during validation.
5. Rewrite the `get_report_summary` RPC to aggregate counts based on array intersections instead of direct string matches.
6. Update `/lib/microsoftGraph.ts` and email dispatchers to determine which template to load when a lead has multiple policies.

**Phase 3: UI & Forms (Frontend)**
7. Modify `Intake Forms` (e.g., `AutoInsuranceForm.tsx`) to allow multi-select or composite form submissions.
8. Update `/app/(dashboard)/*` pages and `Dashboard Widgets` to render maps of tags instead of a single string text block.
